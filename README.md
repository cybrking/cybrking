# Travis Felder

I build AI developer tools and application security tools: model routing for coding agents, threat modeling, dependency reachability analysis, and security scanners.

## Featured: ModelRudder

[**ModelRudder**](https://github.com/cybrking/modelrudder) adds experimental local LLM routing to **OpenAI Codex CLI** and **Claude Code**. It uses TypeSafe Jev to select models for tasks while the native coding tools retain their tools, approvals, and workspace permissions.

Free MIT-licensed community preview. Bring your own provider account and Jev key. Routing is experimental; savings and task quality are not guaranteed.

[Explore ModelRudder and installation instructions →](https://github.com/cybrking/modelrudder#readme)

## Application security

- [**Threat Model Kit**](https://github.com/cybrking/threat-model-kit) — Threat modeling for Claude Code and Codex, from ideas and designs to repositories and actionable engineering controls.
- [**Reachability Toolkit**](https://github.com/cybrking/reachability-toolkit) — Exploitability-aware software composition analysis (SCA) triage with dependency reachability verdicts and VEX rationale.
- [**Antidote**](https://github.com/cybrking/antidote) — Security scanning for Model Context Protocol (MCP) tool servers, including tool poisoning and injection surfaces.
- [**Actions Guard**](https://github.com/cybrking/actions-guard) — GitHub Actions security scanning powered by OpenSSF Scorecard.
- [**thr8**](https://github.com/cybrking/thr8) — Generate PASTA threat models from repositories using Claude AI.
